# Benchmark: free-build construction (diagnostic)

**Task.** On the freshly loaded **A Mightier Oasis-1** Free Build save, make real, visible
construction progress within the game-time budget: a granary, stockpile, wood
production, housing and food, as resources and terrain permit. This diagnostic is not
scored; record which structures you can verify.

**Not allowed.** Recruiting soldiers or building defences.

## Start

If the game says "Site your granary", place a granary on reachable ground near the keep
with `build_structure` and the name `Granary`, and confirm it in the next screenshot.
Then build the rest. Do not spend the run surveying; if a placement fails, read the
feedback and try different ground or prerequisites.
